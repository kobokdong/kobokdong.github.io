C++ 기반 UART 통신 스레드 구현

Qt 앱의 시리얼 통신을 별도 스레드에서 처리하도록 구성했습니다. 화면은 요청과 결과를 신호·슬롯으로 주고받고, 포트의 입출력은 워커가 담당합니다.

  • SerialWorker를 QThread로 이동해 통신 작업 분리
  • 포트 열기·닫기·송신 요청을 메인 화면과 연결
  • readyRead에서 줄 단위로 수신하고 화면에 데이터 전달
  • 연결 성공·실패 상태 전달 및 종료 시 워커 정리 연결

담당 구현의 통신 흐름

MainWindowUI 스레드 · 제어 요청 / 화면 갱신
⇄

⇄

작업을 나누는 기준

이벤트 루프를 가진 워커 스레드에서 시리얼 포트를 생성하고 관리합니다. 화면과 통신 객체의 역할을 나누어 입출력 처리와 UI 코드를 분리했습니다.

데이터를 전달하는 방식

115200 baud, 8N1로 통신합니다. 수신 데이터는 줄바꿈을 기준으로 읽고 문자열로 전달해, 화면에서 온도·습도 정보를 해석하도록 연결했습니다.

연결 수명 관리

포트 연결 상태를 신호로 전달하고, 재연결 시 포트 중복 열기를 확인합니다. 스레드 finished 신호와 deleteLater를 연결해 워커 정리를 구성했습니다.

팀 구현 범위와 확장 과제 보기

팀 전체 구현은 DC 모터 PWM, 서보 조향, LED 방향지시등, DHT11 온습도, 카메라 표시, 주행 종료 기록을 포함합니다. 위 기능 전체를 개인 기여로 주장하지 않으며, 개인 담당은 Qt 앱의 UART 통신 스레드입니다.

  • 화면의 속도 및 평균·최고 속도는 슬라이더의 제어 설정값에 기반합니다. 실측 차량 속도로 소개하지 않습니다.
  • 확장 과제: 사용자가 시리얼 포트를 선택하는 기능, 케이블 분리 시 오류 처리, 수신 프레임 검증 강화.
  • Qt 종료·중립 명령과 MCU 명령 해석의 일관성은 추가 통합 검증이 필요합니다.

02
FIRMWARE PROJECT · STM32F411

UART & 버튼 기반 모터 제어

UART 문자 명령과 버튼 입력으로 모터의 회전 방향, 정지, PWM 듀티를 제어하는 펌웨어입니다. HAL·RTOS 없이 CMSIS 장치 헤더와 레지스터 직접 접근으로 주변장치를 설정합니다.

CSTM32F411CMSISUARTPWMEXTI · Timer Interrupt
CONTROL STATES / TIM5 PWM
CW⇄STOP⇄CCW

F / R / S → 방향·정지 명령
1–9 → 듀티 50–90% 설정 · 신호는 개념도

IMPLEMENTATION FOCUS

입력·상태·출력으로 나눈 제어 흐름

USART2와 버튼 EXTI 인터럽트에서 입력 상태를 갱신하고, 메인 루프에서 변경된 모터 상태에 맞춰 출력을 적용하는 구조입니다.

방향 전환 시 출력을 먼저 정지하고 TIM4 만료 후 반대 방향으로 전환합니다. TIM2는 버튼을 누른 시간을 판별하는 데 사용합니다.

주변장치 직접 설정

GPIO 모드와 대체 기능, USART2, NVIC, 타이머 레지스터를 설정합니다. PA0·PA1을 TIM5의 두 PWM 채널로 사용합니다.

두 가지 입력 경로

UART 문자로 CW·CCW·정지와 듀티 단계를 지정합니다. 버튼은 누름 시간에 따라 시작·방향 전환·정지 요청을 구분합니다.

타이머별 역할 분리

TIM2는 버튼 시간 측정, TIM4는 약 1초의 방향 전환 대기, TIM5는 모터 PWM 생성에 사용합니다. PWM은 개방 루프 듀티 제어입니다.

현재 구현 범위와 검증 과제 보기

엔코더 피드백과 PID 속도 제어는 포함되어 있지 않습니다. PWM 주파수와 버튼 시간은 코드 설정에 기반하며, 이 포트폴리오 작성 과정에서 보드 측정이나 펌웨어 빌드를 수행하지 않았습니다.

  • 반복 버튼 입력 시 누름 시간 초기화와 접점 디바운싱 검증.
  • 방향 전환 대기 중 정지 명령 및 버튼·UART 동시 입력 처리 개선.
  • 인터럽트 안의 출력 처리를 줄이고 실제 PWM 파형과 입력 지연 측정.
